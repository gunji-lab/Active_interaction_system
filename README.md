# 講義レスポンス

大学の講義向けの、小さな匿名回答アプリです。静的な画面を GitHub Pages に置き、認証とデータ保存に Supabase を使います。教員は講義と複数の問題を作成し、1問ずつ出題します。学生は参加コードまたはQRコードで入り、選択式・数値・自由記述で回答します。

## できること

- 教員: メールとパスワードでログイン、講義・問題の作成と編集、QRコード表示、回答をリアルタイムに確認
- 学生: アカウント不要で回答。3秒ごとに新しい出題や公開状態を確認
- 公開操作: `受付開始` → `受付終了` → `回答分布・一覧を公開` → `正解・解説を公開`
- 回答は端末のランダムなトークンにつき各問題1回。教員画面では原文と件数、学生画面では公開後だけ匿名の回答一覧を表示
- 数値は全角数字、全角小数点・符号、桁区切りカンマ、指数表記（例 `1.5e-3`）を受け付け、集計時に同じ値へ正規化

## Supabase の準備

1. [Supabase](https://supabase.com/) で新規プロジェクトを作る。
2. **SQL Editor** で [`supabase/schema.sql`](supabase/schema.sql) の内容を実行する。既存プロジェクトに適用する場合は、同名のテーブルや関数がないことを先に確認する。
3. **Authentication → Providers → Email** でメール認証を有効にする。教員アカウントは **Authentication → Users → Add user** から作成する。公開サイトで教員アカウントを勝手に増やされたくない場合は、一般向けの新規登録を無効にする。アプリ内に新規登録画面はありません。
4. **Project Settings → API** から `Project URL` と `anon` / `publishable` キーを控える。`service_role` / secret キーは画面や GitHub に入れない。
5. 本番運用前に Supabase の **Authentication → URL Configuration** に公開サイトのURLを設定する。

SQL は、教員本人だけに自分の講義・問題・回答への直接アクセスを許可します。学生にはテーブルへの直接アクセスを許可せず、`student_view` と `submit_answer` の関数だけを使わせます。`student_view` は公開前の回答や正解を返しません。

## ローカルで動かす

Node.js 20 以上を用意します。

```sh
npm ci
cp .env.example .env
```

`.env` に Supabase の Project URL と公開キーを入力してから:

```sh
npm run dev
```

表示されたURLを開きます。`?teacher=1` が教員画面です。`npm run build` で型検査と本番ビルドを行います。

## GitHub Pages に公開

1. このフォルダを GitHub リポジトリに入れて `main` ブランチに push する。`.env` は push しない。
2. リポジトリの **Settings → Secrets and variables → Actions → Variables** に `VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` を登録する。これらは公開可能な値であり、ビルド済み画面に含まれます。
3. **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選ぶ。
4. `main` への push で `.github/workflows/deploy.yml` がサイトを公開します。
5. サイトのトップURLに `?teacher=1` を付けて教員ログインを開きます。講義を作成すると参加URLとQRコードが表示されます。

Cloudflare Pages でも、ビルドコマンド `npm run build`、出力ディレクトリ `dist`、同じ2つの環境変数で公開できます。

## 授業での使い方

1. 教員画面で講義を作り、問題文、回答形式、選択肢、正解・解説を登録します。
2. 学生にQRコードまたは参加URLを共有します。学生画面は出題待ちになります。
3. 問題を選び「この問題を出題・受付開始」を押します。教員画面には回答と件数が約3秒ごとに更新されます。
4. 「受付終了」を押すと新しい回答を受け付けません。「回答分布・一覧を公開」で匿名の集計と原文リストを学生に公開します。「正解・解説を公開」は別操作です。
5. 次の問題を選んで出題します。前の問題の回答は教員画面に残ります。

## 運用上の範囲

- 同じブラウザの同じ端末からは、各問題に最初の回答だけを保存します。ブラウザの保存データを消す、別端末を使うなどすれば再回答できるため、厳格な本人確認や採点には適しません。
- 図は授業のスライドで見せ、アプリには問題文と回答欄を表示します。
- 回答一覧を公開すると自由記述の原文も全員に見えます。個人情報を書かないよう学生に案内してください。
- 現行版には回答の削除、CSV出力、授業の終了後に参加コードを無効化する機能はありません。参加コードを知る人は公開中の問題と公開済み回答を閲覧できます。
- 大規模授業では3秒ごとの確認が Supabase の利用量を増やします。必要なら間隔や利用プランを調整してください。

以前の画像アップロード版でSupabaseを設定済みの場合、新しいSQLを再実行すると学生画面への画像表示は止まります。画像保存用バケットと既存画像は自動削除しません。不要になった画像は Supabase の Storage 画面で確認して削除してください。
